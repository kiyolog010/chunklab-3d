One-time console setup
  1. Open console.firebase.google.com and create a project (Spark plan, no card).
  2. In Project settings → Your apps, add a Web app and copy the firebaseConfig object.
  3. Authentication → Sign-in method → enable Anonymous.
  4. Firestore Database → Create database → paste the rules below into the Rules tab.
  5. Paste the config below and press Connect. Then bake it into the file (see the note under the buttons) so visitors connect too.
Firestore rules 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /artifacts/{appId}/public/data/{col}/{docId} {
      allow read: if true;
      allow create, update, delete: if request.auth != null;
    }
    match /artifacts/{appId}/users/{uid}/profile/{docId} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
Firebase web config

Accepted as JSON or as a pasted const firebaseConfig = {...}; snippet. The config is public client data — it identifies the project, it does not grant admin access.

Connecting saves the config in this browser and reloads, so you can test immediately. For visitors, use Download configured build — it bakes the config into a copy you can host anywhere (GitHub Pages, Netlify, Drive). Hosting on a single file keeps every visitor on the same Firestore project.
